# spaniel commands

Commands shared in the [spaniel.dev](https://spaniel.dev) blog, hosted at [spaniel.sh](https://spaniel.sh) via GitHub Pages.

Each file in this repo is served at `https://spaniel.sh/<name>`, so an article can link to a one-liner instead of including the whole script. Read a script before you run it:

```bash
curl -fsSL https://spaniel.sh/<name>
```

## Commands

| Command | What it does | Run it |
| --- | --- | --- |
| [`emudhra-check`](emudhra-check) | Checks which terminal tools on a Mac still trust the distrusted eMudhra roots | `curl -fsSL https://spaniel.sh/emudhra-check \| bash` |
